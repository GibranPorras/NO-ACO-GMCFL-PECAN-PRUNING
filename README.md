# GMCFL-guided ACO Framework

This repository contains the official implementation of the **GMCFL-guided Ant Colony Optimization (ACO)** framework, as presented in our research paper.

## 📋 Overview
The implementation of the proposed framework, together with the experimental instances used to reproduce all tests reported in this study, is publicly available in this GitHub repository. The repository includes the complete **MATLAB** source code and the required data to ensure transparency and reproducibility of the experimental results.

## 🚀 Contents
* **MATLAB Source Code:** Full implementation of the GMCFL-guided ACO metaheuristic.
* **Experimental Instances:** Dataset used for the pruning constraints and LiDAR-derived tests.
* **Reproducibility:** Documentation and scripts to replicate the study's results.

## 🔧 Usage
1. Clone this repository:
   `git clone https://github.com/GibranPorras/NO-ACO-GMCFL-PECAN-PRUNING.git`
2. Open the project in MATLAB.
3. Run the main execution script to start the optimization process.
